How to use the Refresh Rate test

  1. Open this page on the screen you want to test and keep the tab in front. Wait a few seconds for the number to settle.
  2. Read the measured Hz and the likely refresh rate under it. It should match your monitor’s setting.
  3. Watch the frame-time graph: an even line is smooth, and red bars are dropped frames.
  4. Compare the moving lanes. The top lane updates every frame; the lower lanes show half and quarter frame rate.
  5. If the number is too low, check your display settings, cable and graphics driver, then press Measure again.

Frequently asked questions

Why does the test show 60 Hz on my 144 Hz monitor?

Usually the monitor is set to 60 Hz in your operating system (Windows: Settings → Display → Advanced display; macOS: Displays → Refresh Rate), the cable or port can’t carry the higher rate, or the browser is limiting frame rate in battery-saver mode.

How accurate is a browser refresh rate test?

Browsers draw once per screen refresh, so timing many frames gives an accurate average, usually within a fraction of a Hz. Busy computers can drop frames, so close heavy apps for the cleanest result. Variable refresh (G-Sync, FreeSync) may show a range.

What are dropped frames?

A dropped frame is a refresh where the browser could not draw in time, so a frame took two or more refresh intervals. A few are normal; many in a row cause stutter. Switching tabs pauses the test because hidden tabs don’t draw.

What does the motion test show?

All lanes move at the same speed, but the lower lanes only update every second or fourth frame. On a high refresh screen the top lane looks clearly smoother, which is the benefit you get from a higher refresh rate.
