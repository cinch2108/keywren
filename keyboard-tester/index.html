    How to use the Keyboard tester

    1. Press any key. It turns bright while held and stays green once it has been tested.
    2. Work across the whole keyboard until “Keys tested” reaches the total, including F-keys, arrows and the numpad.
    3. Check the Last key event panel for event.key, event.code, keyCode, location (left, right or numpad) and modifiers.
    4. To test ghosting, hold several keys together (for example W, A, S, D and Space). Every key you hold should appear in the list.
    5. “Block browser shortcuts” stops keys like F5, Tab and Space from scrolling or reloading the page. Untick it to use Tab normally.

    Frequently asked questions

    What is keyboard ghosting?

    Ghosting is when a keyboard can’t detect a key because of the other keys you are holding. Cheap keyboards share wiring between keys, so some combinations silently drop a key press. Hold your common game or shortcut combos here to see if any key goes missing.

    What does N-key rollover (NKRO) mean?

    Rollover is how many keys a keyboard can register at the same time. 6-key rollover is common on USB keyboards; NKRO keyboards register every key. The “Most keys at once” box shows the most simultaneous keys Keywren saw.

    Why don’t some keys work in the tester?

    Some keys are handled by your operating system before the browser sees them, such as the Windows key on some systems, Fn, media keys and Print Screen (which may only send a key-up). Laptops also combine keys with Fn in hardware.

    What is the difference between event.key and event.code?

    event.code is the physical key position (for example KeyQ), which stays the same in every language layout. event.key is the character it produces, such as “q”, “Q” or “a” on an AZERTY keyboard.
