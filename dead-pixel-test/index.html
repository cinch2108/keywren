How to use the Dead Pixel test

  1. Clean the screen first so dust is not mistaken for a dead pixel.
  2. Press Start fullscreen test (or F). The first screen is solid black.
  3. Use the → and ← arrow keys, Space, or a click to step through black, white, red, green, blue and the other tests.
  4. On each colour, scan the whole screen slowly, including the corners. Press H to hide the label so it doesn’t cover anything.
  5. Press Esc to exit. Use the dark grey and gradient tests in a dark room to check for glow, bleed and banding.

Frequently asked questions

What is the difference between a dead and a stuck pixel?

A dead pixel stays black on every colour, which shows up best on the white screen. A stuck pixel stays one colour (often red, green or blue) and shows up best on black or a contrasting colour. Stuck pixels can sometimes be fixed; dead pixels usually can’t.

How many dead pixels are acceptable?

It depends on the maker’s pixel policy. Many manufacturers only replace a monitor with several dead or bright pixels, and some promise zero bright pixels. Check your warranty and test as soon as you buy a screen so you can return it in time.

What is backlight bleed?

Light from the backlight leaking around the edges of an LCD panel, visible as bright patches on a dark screen. Use the black and dark grey tests in a dim room. A little glow on IPS panels at an angle is normal.

Does this test work on phones and TVs?

Yes. Open the page in your phone or smart TV browser and use fullscreen. On touch screens tap to go to the next colour. Some phone browsers don’t allow fullscreen; the test then fills the browser window instead.
